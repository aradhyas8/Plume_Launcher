Install in a minute

Plume isn't on the Play Store. Install it straight on your TV with the free Downloader app.

Downloader code

2125356

Always points to the latest release.

  1. Get DownloaderSearch the Play Store on your TV for Downloader by AFTVnews and install it.
  2. Enter the codeOpen Downloader, type 2125356 and select Go. Allow Downloader to install apps when asked.
  3. Open PlumeInstall, then open Plume from your apps. Its settings open on first launch to set the Home button and default launcher.
Other ways to install

USB drive. Download the APK, copy it to a USB drive and open it with a file manager on the TV.

adb. From a computer on the same network:

adb install Plume-1.7.apk

Android 13 and newer. Android greys out the Home button switch for apps installed outside the Play Store. The README explains the one-time fix.

After that, Plume updates itself from Plume settings → Updates.
