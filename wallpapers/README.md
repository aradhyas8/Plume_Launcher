# Wallpapers

Select **Plume settings → Wallpaper → Built-in → More photos** to download this collection from GitHub.
Downloads use the files in this directory on the `main` branch. They become available when this PR merges.
The download contains eighteen WebP files, 2,417,814 bytes in total. The launcher downloads them only after the user selects the button.

Porcelain Dunes also ships in the APK as a 21,584-byte WebP. It is the only wallpaper in the APK and the default for light and dark mode.
Mist and Peak moved from the APK to this pack. A saved Mist or Peak choice keeps its picture after the pack downloads, and shows Porcelain Dunes until then. The bundled copy uses quality 75; the optional copy uses quality 92.
Both copies are 1920×1080. The generated sources are 1672×941, so these are resized exports, not native 4K.
