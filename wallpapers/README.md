# Wallpapers

Select **Plume settings → Wallpaper → Built-in → More photos** to download this collection from GitHub.
Downloads use the files in this directory on the `main` branch. The new files become available after merge.

The pack contains ten 1920 × 1080 WebP images, with a total size of 2,169,808 bytes (2.2 MB).
The project owner supplied these files. The app downloads them only when you select **More photos**.

| Wallpaper | Theme order |
|---|---|
| Alpine Dawn | Light |
| Forest Mist | Light |
| Coastal Dusk | Dark |
| Autumn Canopy | Dark |
| Arctic Aurora | Dark |
| Sand Dunes | Light |
| Aerial River | Light |
| Ocean Reef | Light |
| Cherry Blossom | Light |

Both themes show all ten wallpapers. The theme changes their order.
No wallpaper image currently ships inside the APK. New installations use a plain colour.
Old bundled and pack selections fall back to a plain colour until you select another wallpaper.
